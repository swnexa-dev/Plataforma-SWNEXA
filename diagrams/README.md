# Diagramas

Esta pasta receberá diagramas visuais aprovados para divulgação pública.

Enquanto não houver exportações sanitizadas, os diagramas conceituais em Mermaid permanecem na documentação Markdown. Não adicione diagramas que revelem hostnames, faixas de rede, identificadores de conta, endpoints internos, credenciais ou detalhes proprietários de implementação.
