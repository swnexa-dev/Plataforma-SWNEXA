# Capturas de tela

Esta pasta é reservada para screenshots revisados e sanitizados. Armazene cada imagem no diretório do produto correspondente.

Antes de adicionar uma imagem, confirme que ela não contém dados reais de clientes, e-mails reais, dados financeiros, tokens, IDs sensíveis, configurações privadas, URLs internas ou qualquer outra informação não pública. Use dados representativos ou devidamente anonimizados.

Diretórios atuais:

- `portal/`
- `fluxio/`
- `produtiv/`
- `extoq/`
- `conciliar/`
